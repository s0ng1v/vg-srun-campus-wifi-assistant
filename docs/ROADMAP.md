# 开发路线

## M0 仓库与界面基线

- 导入 Lens GUI
- 清理预览产物和个人数据
- 补全许可证、说明和 CI

## M1 深澜协议

- Rust 实现 XEncode、换表 Base64、HMAC-MD5 和 SHA-1
- 使用 Python 输出作为测试向量
- 模拟门户覆盖登录、退出和错误分类

## M2 守护进程

- 状态机、退避、单实例和网络事件
- DPAPI 凭据存储
- 命名管道与所有者访问控制

## M3 GUI 接入

- 真实账号与门户配置
- 状态、在线数据和性能监测
- 通知、详情和诊断

## M4 Windows 集成

- 开机任务
- Setup.exe
- 卸载、升级和登录前重启验收
