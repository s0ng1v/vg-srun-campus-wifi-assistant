# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not
open a public issue containing credentials, authentication responses, network
addresses or other personal data.

## Credential rules

- Never include passwords, challenge values, complete login URLs or decrypted
  credential files in bug reports.
- Credentials are encrypted with machine-scoped Windows DPAPI and are never
  committed to this repository.
- Authentication is rejected when the portal does not use HTTPS.

## Supported versions

Only the latest published release is supported with security fixes.
